# Little Drop - Flutter Practical Task #05

Responsive Flutter welcome screen based on the NextGen Institute task brief.

## Included

- Welcome heading and subtitle
- Task-management hero illustration from the supplied design brief
- Rounded Login and outlined Sign Up buttons
- Circular Facebook, Google+, and LinkedIn buttons
- Responsive, scrollable layout for different screen sizes
- Android project configuration ready to open in Android Studio

The preview image is at `screenshots/welcome_screen_preview.png`. It was captured from the web build; run the app on an Android emulator or phone in Android Studio to capture an Android screenshot.

## Run

1. Open this folder in Android Studio.
2. Let Android Studio finish syncing Flutter and Gradle.
3. Select an Android emulator or connected Android device.
4. Press **Run**.

From a terminal in this folder, you can also run:

```bash
flutter pub get
flutter run
```

The buttons display a small message when tapped. This task implements the supplied welcome screen; it does not include a backend or authentication flow.
